해야 할 것

  • 미루는 습관을 탓하지 말고 끝낼 시점을 학생이 정하게 한다
  • 집은 쉬는 곳: 공부는 에듀플렉스에서 정한 시간에 끝낸다
  • 과목별 수업 → 1010노트 → 교과서 학습 → CHAMP 노트 순서를 지킨다
  • 주장에는 근거를 붙여 자기 말로 바꿔 설명하게 한다(페르미 추정 활용)
  • 충분히 생각할 시간을 주고 결과보다 같은 날 끝낸 과정을 인정한다
  • 작은 성취를 함께 기뻐한다(관계가 연료)

  • 당부를 여러 번 반복하기(잔소리로 들림)

  • 등록 전인데 시작이 확정된 것처럼 안내하기
