내부 보고서의 사회적바람직성·응답일치율을 먼저 봅니다(화면값). 신뢰성이 낮으면 해석 강도를 낮추고 탐색 질문을 늘립니다.

3

마음의 바탕부터

일반 보고서는 기초 멘탈리티 → 학습력 → 학습 방식 및 태도 → 상위 멘탈리티 순서로 읽습니다. 생의 에너지(살아가려는 기운)를 가장 먼저 봅니다.

강점에서 출발

높은 요인이 가능하게 하는 행동을 먼저 연결하고, 빨간불은 화살표를 거슬러 뿌리 가설을 세웁니다. 44개를 하나씩 낭독하지 않습니다.

5

기초문장이해와 과목별 종합·성취레벨·기초·심화·보완 CHAMP를 렌더링 화면에서 확인합니다. API 원점수 정답률을 백분위로 쓰지 않습니다.

6

성향 보고서

학생 프로필·학습, 학부모 프로필·양육, 역동, 욕구를 학부모 커뮤니케이션과 킹핀 확인에 씁니다.

대응 관계는 상담에서 결과를 읽는 순서를 잡기 위한 해석 틀입니다. 5G 상담 요소를 기초 멘탈 → 감정·이성 처리와 기반 학습 → 상황·목표·체계와 학습 방식·태도 → 상위 상태 순서로 읽는다는 큐브맵 스터디 설명에 맞춘 것이며, 요인별 공식 매핑표는 아닙니다. 상위 멘탈리티가 낮게 나와도 “성찰시키겠습니다”라고 약속하지 않고 앞 단계부터 확인합니다.

중등·고등 상담에서 특히 볼 것

빨간불은 고등에서 드러납니다

중학교는 허들이 낮아 사고력만으로도 평균이 나옵니다. 고등에서 성적이 한 번 꺾이면 공부를 좋아하는 태도가 줄어듭니다. 이때 버티게 하는 것이 관리력 엔진입니다.

학교 기출이 가장 빨리 귀를 엽니다

학교별 문항 난이도, 고난도 문항 위치, 변별력 유형, 서술형·사고력 비중을 학생의 취약 유형과 연결합니다. 기출 특징은 담당 학교군을 숙지한 상태에서만 씁니다.

원점수와 등급으로 기대감을 묻습니다

취약 유형이 하나씩 채워질 때 다음 시험 원점수가 얼마나 달라질지, 그러면 등급은 어떻게 될지를 학생에게 직접 묻고, 학생의 기대감을 학부모에게 넘깁니다. 숫자는 학생 스스로 추정하게 하고 상담자가 약속하지 않습니다.

학원 정리는 과목 하나씩

고2·고3, 특히 강사·학원이 정해진 학생은 학원 정리가 전제가 되는 경우가 많습니다. 한 과목씩 빼서 그 과목을 학생 스스로의 공부로 만들고, 그동안 개별지도가 나머지 과목의 방어선이 됩니다.

큐브맵 핵심 8가지

매니저가 먼저 이해하고, 학부모에게는 알아듣는 말로 근거를 대는 데 씁니다. 큐브맵 그림을 학부모에게 하나하나 풀어 주지 않습니다.

해석 도구
진단과 해석

피검사와 바운더리

검사 수치는 피검사 결과와 같습니다. 볼 것은 두 가지입니다. 어떤 성분이 정상 범위에서 얼마나 벗어났는지, 그리고 성분들의 조합이 지금 상태를 어떻게 설명하는지입니다. 수치만 받아 들면 매니저는 비서·가정교사에 머물고, 해석해 한 문장으로 설명하고 처방 조합을 내야 전문가가 됩니다.

쓰는 때 상담 첫머리에서 검사를 “지금 상태를 잰 것”으로 소개할 때

구조도

L1–L6, 우리의 무대는 L3

외부 세계 → L1 핵심 의식(정동 느낌·과거 경험) → L2 자의식·지능 센터(인지+감정) → L3 역할·상호작용·성취 경험 → L4 메타인지(객관화·유연성) → L5 자아 정체성 → L6(다루지 않음). 에듀플렉스가 주로 돕는 곳은 L3입니다. L3를 잘 다듬으면 L4·L5는 아이가 스스로 채워 갑니다.

쓰는 때 무엇을 우리가 바꾸고 무엇을 기다릴지 구분할 때

입구

감정 입자도는 모든 정보의 입구

감정을 얼마나 잘게 나눠 알아차리고 말하는가입니다. 입자도 자체는 바꾸지 못합니다. 매니저는 번역기가 되어 “짜증” 안의 서운함·억울함·수치·불안·답답함·실망을 나눠 줍니다. 고운 아이는 우선순위 가지치기, 둔한 아이는 원인 구분을 돕습니다.

쓰는 때 감정이 흔들려 공부 기능이 떨어지는 장면을 다룰 때

이해의 과정

개념 하나가 내 것이 되는 길

표상된 세계 → 감정 입자도 → 집중(초점 맞추기·유지·전환)과 단어·어휘력 → 논리력 → 의미 명료화(CHAMP의 C, 이해) → 비교·대조 → 수용·부정 → 해석된 세계 → 의사결정·행동 → 기억·학습. 대부분의 문제는 L3의 의미 명료화에서 생깁니다.

쓰는 때 “설명 들으면 아는데 혼자는 못 한다”를 분해할 때

두 엔진

사고력과 관리력

사고력은 지능 센터가 정하는 생각하는 힘이고, 데일리 체크로 명료화를 확인합니다. 관리력은 시간 같은 자원을 다루는 힘이며 살펴보기 → 바꿔 보기 → 겪어 보기 → 결과 받아들이기 → 다시 도전의 과정이 곧 주체성입니다. 관리력은 어떤 사교육도 챙겨 주지 않는 영역이고, 둘의 균형을 보는 것이 5G의 핵심입니다.

쓰는 때 능력과 실행의 차이를 나눌 때

변화의 속도

경로 의존성과 재귀적 변화

쟁반에 모래를 깔고 물을 부으면 물길이 나고 계속 그 길로 흐릅니다. 사춘기 전후로 생긴 경로는 오래 갑니다. 습관은 습관을, 애착은 애착을 강화합니다. 그래서 이미 깔린 판 위에 새 경로를 내 주는 코칭이 우리의 일이고, 먼저 학부모를 이해시키고 그다음 아이를 감쌉니다.

쓰는 때 “언제 되나요?”에 답할 때

분석법

화살표 역추적

문제가 보이는 카드에서 멈추지 않고 화살표를 거꾸로 따라가 뿌리를 찾습니다. 메타인지가 막혔다면 유연성·객관화를 거쳐 결국 감정 입자도까지 거슬러 갑니다. 가설은 “이렇게 한 거 아닐까? 확인해 보자”의 형태로 세우고 관찰로 검증합니다. “그래 보여”만으로는 분석이 아닙니다.

쓰는 때 가장 낮은 점수가 아니라 연쇄의 원인을 찾을 때

목표

주도적 학습 성취 경험

학원이 해 주던 것을 하나 정리하고, 아이가 자기 계획을 직접 손보고, 성공이든 실패든 결과를 받아들이고, 그 성과가 성적과 이어질 때 “이게 네 거야”가 됩니다. 이 경험이 생에 대한 애착과 학습 주도성의 순환을 엽니다.

쓰는 때 전략 과목과 학원 정리의 이유를 설명할 때

감정 번역표

“짜증 나요” 속에 들어 있는 것을 나눠 주는 질문과 대응입니다. 입자도 자체는 바꾸지 않습니다.

속내예대응
서운해서열심히 한 것을 아무도 알아주지 않음서운함을 먼저 알아주고, 한 일을 구체적으로 짚어 줍니다.
억울해서잘못한 만큼보다 더 혼남사실관계를 나눠 억울한 부분을 풀어 줍니다.
수치스러워서친구들 앞에서 창피를 당함, 원래 잘하던 과목에서 틀림“틀려도 돼. 수치스러운 건 영원하지 않아.” 이야기를 끝까지 들어 줍니다.
불안해서또 못할까 봐, 시험이 다가옴예상하는 실패와 지금 할 과업을 나누고, 지금 더 푸는 것이 실패 가능성을 줄이는 일임을 알려 줍니다.
답답해서잘하고 싶은데 방법을 모름어디서부터 풀지 시작점을 잡아 줍니다.
실망스러워서노력했는데 결과가 안 나옴노력이 아직 성과로 이어지지 않은 부분을 짚어 줍니다.

묻는 순서: “뭐 때문에 짜증 났는데?” → “네 짜증에는 어떤 감정이 더 들어 있니?” 상대에 맞춰 눈금을 바꿉니다(3단계, 10점, 100점).

왜 이 순서인가

학생의 말보다 검사 결론이 앞서지 않게 하고, 프로그램 설명보다 인식 변화와 행동 기준을 먼저 남깁니다.

16타입 이해 전달 플로우

실제 결과를 먼저 공개하지 않고 전체 지도, 두 결과, 색 배지, 숫자의 뜻을 익힌 뒤 사전 선택과 비교합니다.

기존 학원을 보는 3가지 기준

여기서 대부분 막힙니다. 답하지 못하면 “확인해 드리겠다”로 연결합니다.

내용 이해도학원에서 배운 내용을 실제로 이해하고 있는가?
숙제숙제를 했는가가 아니라, 배운 내용을 활용해 숙제를 하고 있는가?
성취도수업과 숙제를 통해 실제로 무엇을 할 수 있게 되었는가?

“수업을 잘해 준다”, “자료가 좋다”는 답이 나오면 “그걸 통해 무엇이 바뀌었는지”를 묻습니다. 좋은 학원·강사를 부정하지 않고, 소화의 시간이 부족한지를 봅니다.

현재 위치에 따른 성장 경로

구분성장 경로반론 대응
상위권문제 유형 분석 → 실수 원인 분석 → 고난도 접근 → 문제 해결 전략 → 자신감 향상“하루만 나와도 될 것 같다”는 요청에는 풀이 시작 지점과 증명 과정까지 제시할 수 있는지 확인해 보자고 제안합니다.
하위권개념 이해 → 내용 정리 → 이해 여부 확인 → 문제 적용 → 작은 성공 경험성공 경험을 포인트로 잡습니다. 옆에서 설명하며 끌고 갈 힘이 생기고 진도가 안정됩니다.

학부모가 그려야 할 학생의 변화

이해→성취감→자신감→자기판단→자기주도성

“오늘 무엇을 공부해야 할지 알려 줘야 하는 학생”에서 “내가 무엇을 모르는지 알고, 무엇을 공부할지 판단하는 학생”으로. 기대감은 학생에게서 먼저 확인하고 학부모에게 넘깁니다.

학교 시험으로 개별지도 필요성 완성하기

가장 빨리 귀를 여는 지점입니다. 학교 확인 → 기출 특징 제시 → “보완할 유형을 몇 개나 아는가” 역질문 → 개별지도 연결 → 상담관리에서 매일 확인 순서로 씁니다. 담당 학교군을 숙지한 상태에서만 말합니다.

01학교 시험은 학교마다 다르다
02많은 학생을 동시에 관리하는 구조에서는 한 명의 취약 개념·유형을 매일 찾아 즉시 피드백하기 어렵다
03“학교 기출 → 취약점 → 개별지도”로 연결한다. 기출을 많이 안다는 자랑이 아니라 필요한 학습 방향을 구체화하는 것
04개별지도의 핵심은 수업이 아니라 피드백: 설명 → 문제풀이 → 사고 → 확인
05학교 기출 분석 → 취약 유형 확인 → 개별지도 보완 → 상담관리에서 학습 여부 확인 → 다시 적용 → 성취도 확인
06학부모에게는 점수보다 변화 과정을 보여 준다
07좋은 학원을 찾는 것만큼 중요한 것은 아이가 다니는 학교의 시험을 이해하고 부족한 부분을 계속 찾아 주는 것

세팅이 미흡할 때의 후속 연락

최대 3회. 강압적인 분위기가 되지 않도록 “충분히 고민하시고 다시 이야기해도 된다”는 여지를 함께 남깁니다. 다만 타입과 CHAMP 두 가지를 본다는 기준은 흔들지 않습니다.

1차 · 상담 다음 날

지금 세팅대로라면 변화가 더 늦게 만들어질 수 있다는 점을 전하고 괜찮으신지 확인합니다. 타입 결과가 낮으면 이해·사고 훈련이 더 필요하다는 설명을 덧붙입니다.

2차 · 그다음 날

시간대·과목 구성으로 좁혀 다시 확인합니다. “그럼 포기해야 하냐”는 반문에는 포기가 아니라 옆에서 설명하고 그때그때 피드백하며 키워야 하는 단계라고 답합니다.

3차 · 매니저 첫 상담 당일

원장 상담 내용이 매니저 상담과 공유되었는지 확인하고, 세팅이 부족하면 변화를 깨닫는 시기가 늦어질 수 있음을 한 번 더 전합니다.

상담자가 반드시 기억할 7가지

  1. 기존 학원을 함부로 부정하지 않는다
  2. 개별지도를 무조건 권하지 않는다
  3. 상담자의 말보다 데이터를 활용한다
  4. “공부량”보다 “학습 과정”을 본다
  5. 학생의 편안함과 성장을 구분한다
  6. 등록을 서두르지 않는다
  7. 마지막에는 프로그램이 아니라 학생의 미래를 이야기한다

운영 기준

  • 등록상담과 해석상담은 분리합니다. 한 번에 묶으면 등록은 되어도 매니저의 초기 장악이 어려워집니다.
  • 학부모와 학생이 함께 참석합니다. 한 분만 오시면 일정을 다시 잡습니다.
  • 전화에서는 결론을 내지 않고, 데이터는 얼굴을 보고 시각 자료로 제시합니다.
  • 처방 강도는 학생의 에너지 상태를 함께 봅니다. 처음부터 강하게 가는 병원식과 서서히 올리는 헬스클럽식 사이에서, 버틸 에너지가 없는 학생에게 과한 구성을 얹지 않습니다.
  • 길음점에서 해석상담은 원장이 진행하고, 담당 매니저는 프로그램 확정 후 운영 구성에 맞춰 배정합니다. 담당 매니저 배정을 가족 결정 항목으로 쓰지 않습니다.
i
좋은 수업보다 중요한 것은 학생이 그 수업을 자기 것으로 만드는 것입니다. 원장 혼자 잘해서 등록되는 상담보다, 구성원이 편안하게 초기 장악을 할 수 있는 구조를 만드는 상담이 가장 좋은 상담입니다.
